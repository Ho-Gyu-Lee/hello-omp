## Local instruction changes

`SKILL.md` identifies version 3.0.1 and permits explicit Archify/interactive HTML requests or scoped updates under an already approved maintained-project-map declaration. It distinguishes durable documentation from task artifacts, uses staged full-gate validation and byte-identical publication for maintained maps, and separates manually reconciled working-tree navigation from native committed-source evidence. It requires concise nonblocking change notices, one integration owner, scoped freshness/unknowns, and truthful snapshot/status reporting. It disables update checks per invocation, requires authorization for remote brands, preserves browser protections, and separates installation verification from upstream execution. The no-shell fallback edits a template copy in the artifact directory, never the installed template, and discloses gates that could not run. These are agent instructions, not runtime enforcement, a background watcher, or an OS sandbox. Existing upstream authoring and validation contracts remain applicable within the documented evidence-mode boundaries.
