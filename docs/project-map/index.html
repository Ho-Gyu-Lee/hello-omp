    모델 프로필 변경

    추론 강도: 메인·계획·구현·정밀 검토는 xhigh, 디자인·화면 분석·advisor는 high, 탐색·커밋은 medium, 제목·메모리는 low입니다. 고난도 개발 전제를 단순 보조 업무까지 확대했던 일괄 xhigh 설정은 폐기했습니다.

    모델·fallback: Opus 메인·계획·디자인 / Sonnet 구현 / Sol 보조 / Astra 전문 검토입니다. fallback은 판단 Opus↔Astra, 구현 Sonnet→Sol, 보조 Sol→Sonnet, 경량 Luna→Haiku이며 각 역할의 추론 강도를 명시합니다. 일반 대화에서 커밋을 언급했다고 메인 모델이 자동으로 commit 역할로 바뀌지는 않습니다.

    구현 역할 변경(2026-10-10). 품질 우선 결정으로 task를 Sonnet 5.5 xhigh(fallback Sol 6.1 xhigh)로 바꿨습니다. f80f66e 작성 PC는 두 설정 키만 omp config set으로 적용했고, 9ba300b 작성 PC와 ccb663d 작성 PC는 setup.ps1, macOS는 setup.sh 전체 적용으로 반영했습니다. 새 task 서브에이전트가 anthropic/claude-sonnet-5-5·xhigh·fallback 아님으로 실행된 기록은 두 작성 PC의 것(sources.json → taskRoleUpdate · windowsLocalApply)이며, ccb663d 작성 PC와 macOS는 저장값·유효값만 확인했습니다. 메인과 구현이 Anthropic 한도·인증에 함께 의존하며 실제 소모량은 사용량 기록으로 확인합니다. fallback 시 교차 검토 조건은 역할표를 따릅니다. 작성 PC 근거 .omp-artifacts/task-role-sonnet-20261010-7c1e/ · .omp-artifacts/sync-20261011-f80f66e/는 각 PC에만 있습니다.

    Fable 5.1: 고난도 명시 선택은 /model anthropic/claude-fable-5-1:xhigh를 사용합니다. 기본 역할·자동 fallback 대상에는 넣지 않으며 선택한 세션도 오류·quota 복구 정책을 적용받습니다. 전체 역할표 · 구독·API 경계

    10-11 ccb663d 작성 PC 전체 적용(9ba300b). 실행 정책이 모든 범위에서 Undefined라 사용자 승인으로 자식 PowerShell에만 RemoteSigned를 지정해 setup 종료 코드 0을 확인했습니다. 관리 설정 22개 저장값·유효값과 OKF 31개 파일이 소스와 일치하고 config.yml은 바이트 그대로입니다. 배포본 변화는 원격 공개 OKF 8개뿐이며 로컬 전용 지식 2개 파일을 바이트 보존했습니다. 9ba300b 작성 PC의 f80f66e 적용 기록은 sources.json → windowsLocalApply, f80f66e 작성 PC의 10-08 기록은 peerWindowsApply, ccb663d 작성 PC의 기록은 localCloneApply, macOS의 기록은 knowledgeRestore · macCommitPublish에 보존합니다. 배포·설정 근거 .omp-artifacts/sync-local-20261011-afb5aa57/는 ccb663d 작성 PC에만 있습니다.

    잔여 1% 정책·advisor 활성·모델 ID·7개 선택 목록·인증 방식은 유지했습니다. 역할별 기본값이며 자동 난도 판정을 구현한 것은 아닙니다. 1% 전환은 신뢰 가능한 coding-plan 사용량·적격 후보가 있을 때 적용합니다. API 크레딧 잔액·월 지출 상한·구독 권한·품질 향상은 보장하지 않습니다.

    10-08 모델 프로필 작성 환경의 역할별 실호출 기록은 sources.json → modelProfileUpdate에 구분해 보존하며 이번 동기화의 실행 결과로 세지 않습니다. 현재 실행 중인 메인 모델은 설정 배포만으로 바뀌지 않습니다.
