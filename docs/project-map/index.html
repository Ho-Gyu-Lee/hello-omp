    모델 프로필 변경

    추론 강도: 메인·계획·구현·정밀 검토는 xhigh, 디자인·화면 분석·advisor는 high, 탐색·커밋은 medium, 제목·메모리는 low입니다. 고난도 개발 전제를 단순 보조 업무까지 확대했던 일괄 xhigh 설정은 폐기했습니다.

    모델·fallback: Opus 메인·계획·디자인 / Sol 구현·보조 / Astra 전문 검토를 유지합니다. 판단 Opus↔Astra, 실행 Sol→Sonnet, 경량 Luna→Haiku의 대상은 그대로 두고 각 역할의 추론 강도를 명시합니다. 일반 대화에서 커밋을 언급했다고 메인 모델이 자동으로 commit 역할로 바뀌지는 않습니다.

    Fable 5.1: 고난도 명시 선택은 /model anthropic/claude-fable-5-1:xhigh를 사용합니다. 기본 역할·자동 fallback 대상에는 넣지 않으며 선택한 세션도 오류·quota 복구 정책을 적용받습니다. 전체 역할표 · 구독·API 경계

    Windows 로컬 적용·실호출 확인. setup 종료 코드 0, 설정 22개·OKF 42개 파일 일치를 확인했습니다. Opus xhigh 메인이 Sol xhigh 작업자·Astra xhigh 보안 검토자·Sol medium scout를 실행했습니다. @commit은 Sol medium, @advisor는 Sol high, Sonnet 후보·Fable 명시 선택은 xhigh로 실행 기록을 확인했습니다. 배포 근거 · 실행 모델·강도

    잔여 1% 정책·advisor 활성·모델 ID·7개 선택 목록·인증 방식은 유지했습니다. 역할별 기본값이며 자동 난도 판정을 구현한 것은 아닙니다. 1% 전환은 신뢰 가능한 coding-plan 사용량·적격 후보가 있을 때 적용합니다. API 크레딧 잔액·월 지출 상한·구독 권한·품질 향상은 보장하지 않습니다.

    순서: 사전 검사 → 설정 → 규칙 → OKF → 확장 → agents → commands → skills

    설치는 Archify 실행이 아닙니다. 전체 setup은 트랜잭션이 아닙니다. 실행 근거

    신선도는 부분 대조입니다. 병합하며 읽은 입력 10개는 hash를 다시 계산했고, 이번 검토 밖인 coding-style · language-style의 기존 미대조 fingerprint 2개는 유지합니다. 관계도 구조는 바뀌지 않았습니다.
