# 축적 지식

개인별·환경별로 누적되는 영속 지식의 진입점이다.

이 디렉터리는 **개인 선호·프로젝트 한정 사실·내부 사례의 근거와 공개 범위를 검토 중인 지식**을 보존한다. concept 파일은 `.gitignore`로 로컬 전용이며 공개 레포에 커밋하지 않는다. setup은 파일시스템 복사이므로 Git 제외 여부와 무관하게 배포한다. 로컬 전용이라는 사실이 비밀정보 저장을 허용하지는 않는다.

발견은 이 index의 정적 목록이 아니라 `/learned/` 디렉터리를 직접 읽어 각 concept의 frontmatter 요약으로 한다(로컬 목록을 커밋 트리에 남기지 않기 위함).

기록·공개 반영 판정의 정본은 [OKF 학습 축적 루프](/learning/accumulation.md)다.
* 개인 선호·프로젝트 사실과 공개 가능한 기술 지식을 구분한다. 공개 API 계약도 벤더 한정이라는 이유로 제외하지 않으며, 개인 선호를 공통 규칙으로 승격하지 않는다.
* 신규 작성·갱신·재사용·정정 시 관련 항목을 재평가한다. 본문에는 공개 반영 대상·항목 또는 로컬 유지·보류 사유를 남긴다. 참고 링크만으로 승격 완료를 주장하지 않는다.
* concept은 YAML frontmatter와 non-empty `type`을 갖추고 로컬 상세 이력은 해당 파일에만 기록한다. 비밀정보·PII·내부 접속정보는 기록하지 않는다.
