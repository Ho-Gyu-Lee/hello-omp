# 보안

* [보안 개요](/security/overview.md) - 요청 범위와 무관한 즉시 경고, 취약점 설명·민감정보·Git 원격 자격증명 처리, 외부 자료의 신뢰 경계, 외부 코드 실행·승인·guard 우회 금지, OMP 승인과 실행 격리의 구분.
* [게임 클라/서버 보안](/security/game.md) - 서버 권위·AI 판정의 신뢰 경계, 보안과 반응성의 균형, 대상 인가, 세션 재개·TLS 0-RTT·UDP 사전 할당, 정보 가시성, Lua bytecode와 출하 테스트 훅.
* [코드 리뷰 보안 체크리스트](/security/review-checklist.md) - 리뷰에서 놓치기 쉬운 환경·도구 특이 계약(헤더 변환 우회, 게이트웨이 신원 헤더의 제거와 대체 진입점을 통한 우회, 출발지 IP 허용 목록이 보는 주소와 `X-Forwarded-For` 위조 가능성, 로드밸런서 보안 그룹의 재조정·공유, 자기 공인 IP로 돌아오는 연결, NACL CIDR 정렬과 차단 범위·규칙 상한, 네트워크 정책 집행 여부, IAM 시뮬레이터의 리소스 정책 평가와 적용되지 않는 Deny 조건, 비밀을 응답하는 조회 권한, 저장소 설정의 Git 실행, Windows 실행 파일 탐색, 경로 별칭, 무인 설치의 비밀 키 초기화와 파일 secret 복사). 일반 보안 항목과 게임 항목은 다루지 않는다.
* [클라우드 침해 조사의 로그 공백·신원 판별·노출 범위 (AWS·GCP)](/security/cloud-incident-forensics.md) - AWS·GCP 침해 조사에서 "기록 없음"이나 "탈취 사용"으로 판정하기 전에 확인할 비자명 계약 — 보존이 짧은 출처와 로그 수집기 배치가 만드는 공백, CloudTrail의 리전·트레일 중지·이벤트 기록 한계와 요청 본문을 가리는 API, EKS 토큰 검증과 Lambda 환경 변수 복호화가 남기는 정상 흔적과 IAM 거부로 막히지 않는 EKS 인증과 출발지 거부에 막히는 첫 비밀번호 변경, Lambda 실행 역할의 함수별 세션, 데이터 이벤트만 쓰는 자격 증명의 기준선, 데이터 이벤트 없이 SSE-KMS 객체 읽기를 드러내는 KMS 흔적, EventBridge 경보 규칙의 상태·패턴 상한, 접근 로그 읽기와 CloudFront 지연 전달 함정, 애플리케이션 로그의 교차 테넌트 신호와 로그에 남은 비밀번호의 사용 판정·로그인 계정 귀속, VPC 흐름 로그의 Lambda ENI 공유·NLB 집계 함정과 응답 크기 기준의 한계, 노출 범위(Terraform state·Lambda 관리형 정책·발행 버전에 고정된 실행 역할과 `LastModified` 해석·소스 함수 ARN 조건의 적용 범위), GCP 데이터 접근 로그 공백과 대체 근거, 키 교체 없이 출발지로 제한하는 수단의 한계를 다룬다.
* [요청 서명 정규화 계약 (크로스 런타임)](/security/signing-canonicalization.md) - 서명자와 검증자의 서명 입력 바이트를 맞추는 계약 — rawBody와 canonical 재구성의 구분, 정렬·값 표현·키 집합의 양측 동시 변경, UTF-16/UTF-8 정렬 차이.
