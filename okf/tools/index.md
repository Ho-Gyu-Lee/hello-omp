# 도구

* [omp 기본 도구](/tools/builtin.md) - 내장 도구 우선, AST·glob·긴 작업 timeout·브라우저의 비자명 계약, 실행·관측 주체의 구분, 원본 보존, 작업용 스크립트는 TypeScript+Bun.
* [MCP 정책](/tools/mcp.md) - 내장으로 안 되는 외부 연결만 MCP, 검색 MCP의 수직 검색 선별, gateway 간접 실행 도구, 실행 경로별 backend 버전, 사양 revision과 OMP 호환.
* [스킬 사용](/tools/skills.md) - 매칭 스킬 사용, OMP의 스킬 발견·호출·레지스트리 계약, 외부 스킬 도입과 미검증 저장소 세션 시작의 경계.
* [서브에이전트 위임](/tools/subagents.md) - 직접 처리와 위임의 경계, 상속되지 않는 지침을 포함한 위임 계약, 후보별 독립 생성, 격리·독립 clone, 반환 결과 수락.
