# 도구

* [omp 기본 도구](/tools/builtin.md) - 내장 도구 우선과 비자명 계약(AST 기본값·브라우저·bash 서비스 셸·Windows `/dev/null`·`omp` CLI 인자·`omp://` 문서 지연), 실행·관측 주체 구분, 실행 중 파일의 분할 편집 금지, 긴 작업의 실패 판정, 원본 보존, TypeScript+Bun 작업 스크립트. 셸·eval·브라우저로 실행·관측하거나 작업 스크립트를 쓸 때 읽는다.
* [MCP 정책](/tools/mcp.md) - 내장으로 안 되는 외부 연결만 MCP로 쓰는 기준, 겹치는 MCP 기능의 대체와 검색 MCP의 수직 검색 선별, gateway 간접 실행 도구의 보호 범위, 실행 경로별 backend 버전, 사양 revision과 OMP 클라이언트 호환, OAuth 서버 첫 연결. MCP 도구를 쓰거나 MCP 서버를 추가·설정할 때 읽는다.
* [스킬 사용](/tools/skills.md) - 매칭 스킬의 사용 원칙, OMP의 스킬 발견·호출·레지스트리 계약, 외부 스킬 도입과 미검증 저장소 세션 시작의 경계. 스킬을 쓰거나 외부 스킬을 들이기 전에 읽는다.
* [서브에이전트 위임](/tools/subagents.md) - 직접 처리와 위임의 경계, 위임 계약(AGENTS.md 비상속·소유·수락 기준), 여러 안의 후보별 독립 생성, 격리·독립 clone, 번들 에이전트 도구 경계와 반환 결과 수락. task로 작업을 위임하거나 반환 결과를 수락하기 전에 읽는다.
