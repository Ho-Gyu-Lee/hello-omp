# 학습 축적

* [OKF 학습 축적](/learning/accumulation.md) - 무엇을 기록하는지(사용자 방향과 모델에 부족한 지식)와 판정 시점·기록 판정 세 질문·보류 사유의 한계, 판정 전 제작 방법을 처방이 아닌 판정 상태로 쓰는 기준과 실패 판정 뒤의 정비, 실수를 원리로 일반화하고 고친 원리 문장의 효과(재발·과잉 적용)를 비용에 맞게 확인, 강조 대신 결정적 검사 제안, 기록 위치(공개 소스·로컬·프로젝트 레포와 프로젝트 AGENTS.md 내용 기준), description을 정본으로 한 index 반영·검증·배포, 승격·공개 반영 커밋 전 원격 동기화와 기록·보류 보고, 모델 세대 교체 뒤 상시 지침 재판정.
